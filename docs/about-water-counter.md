## Half page

Water Counter is a small browser extension for people who use AI chats. It works with ChatGPT, Gemini, and Claude text chats. After an AI response ends, the extension shows an estimated operational water value near that response. It also shows the total estimate for the current chat.

Water Counter does not measure water at a data center. The extension uses public provider information and research methods. These sources do not give one exact value for every AI model or every message. For this reason, Water Counter labels each value as an estimate. It shows the source, the date, the calculation method, and the main limit.

The extension calculates values in the browser. It does not send chat text, response text, or token counts to a remote service by default. It does not save chat text by default. You can pause tracking and erase local records. You can also export a report with the calculation details.

Water Counter is not a tool that you must use. It is a simple way to notice the resource cost of AI chats. It helps users ask better questions about how AI systems work and what they require.

## One page

Water Counter is a browser extension that shows the estimated operational water use of AI chats. It supports ChatGPT, Gemini, and Claude text chats. The extension adds a small value near each completed AI response. It also shows the total estimate for the current chat.

Many AI systems run in data centers. These data centers use electricity and cooling systems. Some cooling systems use water. The exact water use changes with the model, response length, hardware, location, cooling method, and data-center work. A browser extension cannot directly measure the water used by the data center for one chat.

Water Counter does not claim to make that direct measurement. It uses public provider information and research methods to make an estimate. Each estimate has a source and a confidence label. The detail view shows the source date, calculation method, water scope, factor version, and main limit. If the extension does not have a defensible factor, it shows “Estimate unavailable.” It does not create a number to fill the empty space.

The extension waits for the AI response to finish. It does not change the water number for every streamed token. This keeps the chat stable while the AI writes. The extension also avoids duplicate records when the page loads older messages. It keeps totals separate when you open different chats.

Water Counter keeps the calculation local in the browser by default. It does not send chat text, response text, token counts, or conversation identifiers to a remote service by default. It does not save user or AI message text by default. The local record contains only the data needed for the estimate, total, source, and history. You can pause tracking, erase the current chat record, or erase all local records.

The extension has a small popup and an options page. These pages give you control over tracking, display style, units, motion, source review notices, and data deletion. You can export a local report with calculation data and source links. The report does not include message text by default. The extension warns you before it exports page URLs or conversation names because those values can contain private information.

Water Counter is for everyday AI users, developers, climate-conscious people, researchers, and students. It is not a required tool. It is a friendly way to notice a hidden part of AI use. It can help people learn, compare sources, and ask clear questions about the limits of environmental estimates.
